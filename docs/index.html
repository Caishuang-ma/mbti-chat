A FEW THINGS TO KNOW

开始前，你可能想知道。

这里可以直接和 AI 聊天吗？

这个网页展示预设对话，帮助你了解不同风格。实际聊天需要在 Codex 中安装并调用 Skill。

这是一份 MBTI 测评吗？

不是。它提供虚构的对话风格，不判断你的类型，也不用于心理诊断。你可以自由选择和调整喜欢的交流方式。

换个类型，会忘记刚才的话题吗？

同一个聊天中会保留话题、背景和你明确表达的偏好。不保证跨聊天或重启后的记忆。

需要另外付费吗？

Skill 本身按 MIT 许可开源免费。使用 Codex 所需的账号、权限与服务费用由其产品规则决定。
